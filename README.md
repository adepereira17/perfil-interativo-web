# Perfil Interativo Web
Projeto desenvolvido passo a passo com meus alunos do curso de Desenvolvimento Web.

Este repositório registra exatamente o que construímos juntos em sala de aula: um pequeno site de perfil totalmente interativo, criado com HTML, CSS e JavaScript puro. A Ideia foi mostrar, na prática, como cada tecnologia se conecta e como pequenos recursos podem transformar uma página simples em algo vivo, dinâmico e personalizado.

## O que o aluno aprende nesse projeto

### Estrutura com HTML

* Organização de conteúdo usando tags semânticas (header, main, footer).
* Uso de IDs e classes para manipulação posterior no CSS e no JavaScript.
* Estruturação de seções como foto, sobre, interesses, contador e tema.

### Estilização com CSS
* Reset básico e boas práticas de organização.
* Layout centralizado usando containers.
* Estilização de botões com hover, transições e microinterações.
* Efeito de sombra variável na foto.
* Modo noturno aplicado via classe no body.
* Responsividade para telas menores.

### Lógica com JavaScript
Durante o projeto, o aluno aprende a manipular o DOM de forma prática e visível:
* Selecionar elementos com getElementById e querySelectorAll.
* Alterar textos e conteúdos da página dinamicamente.
* Criar e inserir novos elementos, como novos interesses na lista.
* Trabalhar com eventos de clique e funções anônimas.
* Gerar números aleatórios para mudar a cor da borda da foto.
* Trocar temas usando atributos data-* e estilização direta via JS.
* Ativar e desativar o modo noturno com classList.toggle().
* Exibir a data atual formatada para o português.
* Permitir que o usuário altere o nome clicando no título da página.

### Persistência com localStorage 
Um dos momentos mais importantes do projeto é quando o aluno aprende: "uma página pode lembrar das coisas".

Utilizamos o localStorage para registrar quantas vezes o perfil foi visitado e isso abre portas para conceitos futuros como personalização de tema, login, preferências de usuário e muito mais.

## Tecnologias utilizadas
* HTML5
* CSS3
* JavaScript (DOM + Eventos + localStorage)

## Objetivos pedagógicos
O foco desse projeto é colocar o aluno dentro do processo real de construção:
* Entender estrutura, estilo e comportamento.
* Ver na prática o impacto de cada linha escrita.
* Desenvolver raciocínio lógico.
* Ganhar confiança nas três camadas principais da Web.
É um projeto simples, mas extramamente completo para quem está dando os primeiros passos no desenvolvimento web.

## Para quem esse projeto é ideal?
Para iniciantes que estão aprendendo:
* Manipulação do DOM.
* Interação com o usuário.
* Criação de efeitos visuais.
* Lógica básica de programação.
* Organização de código.
